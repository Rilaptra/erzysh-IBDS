## 📋 2. Daftar Isi `PROMPT.md` untuk Setiap Step (Otomatis Dibuat oleh CLI)

Setiap kali kamu memilih sebuah _step_ di CLI, file `.tmp-step-context/step-0X-.../PROMPT.md` akan dibuat dengan struktur standar berikut:

1. **Bagian 1 — Konteks & Instruksi Spesifik Step:** Berisi aturan wajib _step_ tersebut (misalnya pada Step 3 mengingatkan bahwa **lendutan ke bawah bernilai negatif $\Delta < 0$** dan mendukung sumbu **`Z-Up` / `Y-Up`**, pada Step 4 mengingatkan bahwa **beton tidak memakai gaya aksial $P_u$ dan torsi $T_u$**, dan pada Step 7 memerintahkan AI untuk **mengintegrasikan kode prototipe `engine.ts` dari folder `prototype/`**).
2. **Bagian 2 — Daftar File Referensi di Folder Temp:** Merinci nama-nama file `.md` (dan subfolder `prototypes/` bila di Step 7) yang ada di sebelahnya agar AI langsung membacanya.
3. **Bagian 3 — Checklist File Target:** Daftar eksplisit file `.ts` / `.tsx` / `.rs` yang harus diselesaikan pada sesi tersebut.
4. **Bagian 4 — Perintah Verifikasi:** Perintah terminal (`bun check -b`, `cargo test`, dll.) untuk memastikan hasil kerja AI bebas _error_.
5. **Bagian 5 — `## ✍️ 5. Catatan / Prompt Tambahan dari Developer (Custom User Prompt)`:**
   - Saat menjalankan skrip CLI, kamu akan ditanya:
     `Ketik tambahan prompt/catatan khusus untuk Step ini (atau tekan Enter jika kosong):`
   - Jika kamu mengetik sesuatu di CLI, teks tersebut langsung masuk ke Bagian 5 di `PROMPT.md`.
   - Jika kamu menekan `Enter` (kosong), Bagian 5 tetap disediakan di paling bawah `PROMPT.md` sehingga kamu bisa membuka `PROMPT.md` kapan saja dan mengetikkan ide tambahanmu sebelum menyalinnya ke AI!

## 🛠️ 3. Cara Menjalankan Skrip CLI `scripts/ai/step-context-bundler.ts`

Kamu dapat menjalankan skrip pembungkus konteks ini dengan dua cara:

- **Mode Interaktif (Pilih Step & Ketik Tambahan Prompt di Terminal):**
  ```bash
  bun run scripts/ai/step-context-bundler.ts
  ```
- **Mode Cepat Satu Baris (Langsung dengan Nomor Step & Catatan Tambahan Opsional):**
  ```bash
  bun run scripts/ai/step-context-bundler.ts 3 "Pastikan jumlah segmen default M = 256 dan ekspos fungsi ubah sumbu Z-Up/Y-Up ke TS"
  ```
